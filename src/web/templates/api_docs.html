Authentification

Utilisez votre token JWT dans l'en-tête Authorization de vos requêtes :

Authorization: Bearer YOUR_JWT_TOKEN
Obtenir un token :
curl -X POST {{ base_url }}/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email": "your@email.com", "password": "yourpassword"}'
Points d'accès API
POST /api/v1/saas/tts

Génère un fichier audio à partir de texte

Paramètres :
  • text (string, requis) : Le texte à synthétiser
  • voice (string, optionnel) : La voix à utiliser (défaut: auto-détectée)
  • rate (string, optionnel) : Vitesse de lecture (+/-50%)
Réponse : Fichier audio MP3
GET /api/v1/saas/usage

Récupère vos statistiques d'utilisation

Réponse :

Exemples d'utilisation
Python
import requests

url = "{{ base_url }}/saas/tts"
headers = {
    "Authorization": "Bearer YOUR_JWT_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "text": "Bonjour, ceci est un test de synthèse vocale.",
    "voice": "fr-FR-DeniseNeural"
}

response = requests.post(url, headers=headers, json=data)

if response.status_code == 200:
    with open("audio.mp3", "wb") as f:
        f.write(response.content)
    print("Audio généré avec succès !")
JavaScript
const response = await fetch('{{ base_url }}/saas/tts', {
    method: 'POST',
    headers: {
        'Authorization': 'Bearer YOUR_JWT_TOKEN',
        'Content-Type': 'application/json'
    },
    body: JSON.stringify({
        text: 'Bonjour, ceci est un test.',
        voice: 'fr-FR-DeniseNeural'
    })
});

if (response.ok) {
    const blob = await response.blob();
    const audio = new Audio(URL.createObjectURL(blob));
    audio.play();
}
cURL
curl -X POST {{ base_url }}/saas/tts \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"text": "Bonjour monde", "voice": "fr-FR-DeniseNeural"}' \
  --output audio.mp3
